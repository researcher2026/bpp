# Anonymous LLM Tutoring Evaluation Dataset

This repository contains the data supporting the findings of our anonymous submission on modular prompt design patterns for multi-turn LLM agents.

## Contents

- `llm_ratings.json`: Raw ratings collected from the LLM evaluator for each response.
- `llm_analysis_report.csv`: Aggregated evaluation scores across experimental conditions.
- `outputs.zip`: Prompt inputs and LLM-generated outputs used in the evaluation.
- `llm_analysis_report.md`: Summary statistics and visualizations for each metric used in the study.

## Description

The dataset includes:

- **Prompt inputs** used to generate tutoring responses across different experimental conditions.
- **LLM-generated responses**, organized by condition and prompt.
- **LLM evaluation results** across five tutoring dimensions:
  - Scaffolding Quality
  - Contextual Responsiveness
  - Helpfulness
  - Symbolic Strategy Use
  - Memory and Continuity
- **Statistical analysis**

## Notes

- No human subjects were involved in the rating process.
- This repository is anonymized for double-blind review purposes.
